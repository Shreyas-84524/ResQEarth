# ResQEarth Design System & UI Specification

**Descriptor:** ResQEarth — Smart Disaster Intelligence, Preparedness and Emergency Warning Platform  
**Document Status:** UI Source of Truth  
**Version:** 1.0 (Phase 1.2 Baseline)

---

## 1. Design System Principles

1. **Urgency Without Panic:** Visual clarity through balanced contrast, restrained motion, and unambiguous typography.
2. **Accessible Urgency:** Severity is always communicated through **text and iconography** in addition to color (never color alone).
3. **Strict Provenance Differentiation:** Clear visual distinctions between **OFFICIAL ALERT**, **RESQEARTH CALCULATED RISK**, and **MANUAL ADMIN WARNING / SIMULATION**.
4. **Mobile First & Responsive:** Optimized for 360 px mobile viewport through 1920 px desktop displays.
5. **Cognitive Load Reduction:** Scannable cards, clean metadata chips, structured information hierarchies, and predictable interaction patterns.

## 4. Spacing, Radius, and Elevation

### Radius Tokens
- Default: `var(--radius) = 0.5rem` (`rounded-lg`)
- Small: `calc(var(--radius) - 4px)` (`rounded-sm`)
- Medium: `calc(var(--radius) - 2px)` (`rounded-md`)
- Large / Pill: `9999px` (`rounded-full`)

### Shadow Tokens
- `shadow-sm`: Standard card and badge elevation
- `shadow-md`: Hover states and floating overlay panels
- `shadow-float`: Dialogs, emergency modals, and prominent banners

## 5. Component Specifications

### 5.1 UI Primitives (`src/components/ui/`)
1. **Button:** Primary, secondary, outline, destructive, ghost, link, and risk severity variants with loading spinner support.
2. **Input & Textarea:** Accessible focus ring (`ring-2 ring-ring ring-offset-2`), disabled, and `aria-invalid` error states.
3. **Card:** Modular container (`Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter`).
4. **Badge:** Pill indicators with variants for standard, status, provenance, and risk severity.
5. **Alert:** Banner notifications with icon slot and severity/provenance borders.
6. **Dialog (Modal):** Accessible modal dialog with backdrop, escape key support, accessible labels, and close button.
7. **Select:** Accessible dropdown selector with chevron indicator and error state.
8. **Skeleton:** Pulse loading placeholder matching layout geometry.
9. **EmptyState & ErrorState:** Standardized empty and failure states with retry and correlation ID slots.
10. **PageHeader & SectionHeader:** Page/section titles with subtitle, back button, and action slot.
11. **SeverityBadge & SeverityIndicator:** Dual text/icon severity indicators meeting accessibility guidelines.

### 5.2 Common Domain Components (`src/components/common/`)
1. **WeatherCard:** Real-time weather parameters (temp, feels like, humidity, wind, precipitation) with source attribution ("Open-Meteo") and loading/stale states.
2. **DisasterCard:** Scannable disaster event card with icon, title, description, severity badge, provenance badge, location, and safety guide links.
3. **RiskIndicator:** 0–100 score gauge, risk level badge, itemized contributing factors breakdown (+points), model version, and educational disclaimer.
4. **MapOverlay & Legend:** Floating zoom/locate controls, disaster category filter chips, expandable severity/symbol legend, and OpenStreetMap attribution.
5. **AdminDashboardCard:** Operational summary card with numeric value, status badge, trend indicators, and icon.
6. **NotificationBanner:** In-site emergency warning banner with severity color, icon, provenance tag, precautions preview, and safety guide CTA.

## 6. Accessibility (a11y) Standards

- **Color Contrast:** All text meets WCAG AA contrast ratio (4.5:1 for normal text, 3:1 for large text).
- **Non-Color Severity Cues:** Every severity indicator pairs color with explicit text (`LOW`, `GUARDED`, `MODERATE`, `HIGH`, `CRITICAL`) and a unique icon.
- **Focus States:** Every interactive element has an active `:focus-visible` state (`ring-2 ring-ring ring-offset-2`).
- **Screen Reader Announcements:** Hidden descriptive text (`.sr-only`) accompanies icons, badges, and progress meters.
- **Reduced Motion:** Animations respect `prefers-reduced-motion` settings.
